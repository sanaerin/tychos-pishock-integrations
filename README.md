# Tycho's PiShock Integrations
<img width="773" height="432" alt="image" src="https://github.com/user-attachments/assets/6e983fe8-c2b2-4dfe-a2b4-4613dbc288c1" />

Tycho's PiShock Integrations adds PiShock integrations to [Poker Night at the Inventory](https://store.steampowered.com/app/3897800/Poker_Night_at_the_Inventory/) that trigger when a player does poorly or loses. Using [Tycho's Lua Hook](https://www.nexusmods.com/pokernightattheinventory/mods/17), a script listens to in-game events and saves them to a text file for the mod to know when to trigger a shock.

## Limitations at the moment
- Not tested with real PiShock using a sharecode yet
- Need to press keybind again when the table resets on new game, win or loss

## Requirements
- [Tycho's Lua Hook](https://www.nexusmods.com/pokernightattheinventory/mods/17) latest version installed
- [PiShock](https://pishock.com/#/) device with username, API key and a share code 
- Poker Night at the Inventory
