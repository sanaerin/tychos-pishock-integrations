# Tycho's PiShock Integrations

This mod adds PiShock integrations to [Poker Night at the Inventory](https://store.steampowered.com/app/3897800/Poker_Night_at_the_Inventory/) that trigger when a player does poorly or loses. Using [Tycho's Lua Hook](https://www.nexusmods.com/pokernightattheinventory/mods/17), a script listens to in-game events and saves them to a text file for the mod to know when to trigger a shock.
